# Summary and desktop dashboard direction

User-supplied visual reference (2026-09-16):
https://www.schedulevalidator.com/wp-content/uploads/2026/06/image-21.png

Use the general information hierarchy: grouped KPI cards, restrained status
colors, readable tables, and charts placed beside the data they summarize.
Keep XERCompare's own design, labels, and branding. Do not reproduce the image
or the vendor's proprietary scores.

For the current two-file reports, show verifiable activity/change counts,
relationship and assignment changes, and stored-value quality results. Missing
metrics stay N/A with a reason. History charts, financial forecasts, interactive
lookahead controls remain in their later phases. The desktop now includes six
change-count cards, stored-value quality results, and a report-catalog preview.

The Phase 3 report catalog and parser correctness take priority over cosmetics.

Additional product reference:
https://www.schedulevalidator.com/product/ (reviewed 2026-09-16).

The product groups its analyses into quality, finish, progress, execution, and
portfolio views. For XERCompare, this suggests a summary-to-detail structure:

| Group | Current report evidence | Later work |
|---|---|---|
| Quality | DCMA 14 + Warnings, with unavailable checks clearly labeled | Issue registers |
| Finish | Early/Late Finish Changes + Variances | Milestone slippage and history |
| Progress | Actual Date Change + Progress Change | Defined baseline performance metrics |
| Network | Added/Deleted Relationships + Lag Change + stored TF approximation | No CPM recalculation in scope |
| Portfolio/trends | Not part of this two-file run | History phase |

This is a grouping reference, not a specification for proprietary SV scores,
compression windows, execution scores, or cloud uploads.
