# XERCompare 0.3.0 — Public Beta

Compare Primavera P6 XER exports locally and create Excel and PDF reports.
This is the first public beta of the Windows desktop app.

## Download and run

**[Download XERCompare for Windows](https://github.com/clachance14/XERCompare/releases/download/v0.3.0/XERCompare-Windows.zip)**
· **[Read the PDF guide](https://github.com/clachance14/XERCompare/releases/download/v0.3.0/XERCompare-Start-Here.pdf)**

1. Download **XERCompare-Windows.zip** and choose **Extract All**.
2. Open the extracted folder and double-click **XERCompare.exe**.
3. Choose the older and revised XER files, select an output folder, and click
   **Compare schedules**.

Requires 64-bit Windows. No installer, Python, P6 installation, account, or
internet connection is needed to run the app. The ZIP contains the app, PDF
instructions, complete PDF license notices, and two synthetic example exports.
The **Source code** archives are for developers; the Windows app is in
**XERCompare-Windows.zip**.

## Included

- 39 Excel worksheets with before/after values, changed-cell highlights,
  filters, and frozen headers.
- Short PDF summary of changes, finish movement, milestones, logic, and quality.
- Activity, progress, date, calendar definition, constraint, float, relationship,
  resource assignment/value, and activity UDF comparisons.
- Detailed quality findings, search, and saved local check profiles.
- Update history with charts, reviewed file order, optional baseline, and full
  reports for each comparison.
- One decimal for measurements, two for costs; full numeric precision in Excel.

## Beta limits and verification

Compares stored fields; no CPM recalculation. Only the first project in each
XER is modeled. Activity ID renames appear as delete/add. Driving-path membership
uses stored total float at or below zero as an approximation. DCMA checks 11–14
show N/A with reasons. Review findings against the source schedules.

The Windows suite passed 84 tests, including local real-file coverage. The
packaged app passed isolated-runtime checks with network connections blocked,
including comparison, quality drill-down, saved profiles, and synthetic history.
A separate machine without Python has not yet been tested. Detailed scope is in
[verification](https://github.com/clachance14/XERCompare/blob/v0.3.0/docs/VERIFICATION.md).
